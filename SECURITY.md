# Security policy

Overquid runs third-party plugins, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/Kureo524/Overquid/security/advisories/new).
You will get an answer within a week.

In scope: plugin sandbox escapes, permission checks that can be bypassed, anything letting a plugin reach the system
outside the SDK.

## Supported versions

Only the latest release receives security fixes.
